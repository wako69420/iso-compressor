# Security Policy

## Supported Versions
Since this is a personal project, I only actively update and patch the **latest release** (master branch).

| Version | Supported          |
| ------- | ------------------ |
| Latest Release | :white_check_mark: |
| Older Versions | :x:                |

## Reporting a Vulnerability
If you happen to find a security flaw or a critical bug (like a command injection issue in the CLI tools), please **don't open a public issue**. 

Instead, just report it via GitHub's private vulnerability reporting feature in the "Security" tab of this repository. I'll take a look and try to get a patch out as soon as I can!
