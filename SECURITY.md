# Security Policy

## Supported Versions
We currently only provide security and bug fix updates for the **latest release** (master branch).

| Version | Supported          |
| ------- | ------------------ |
| v1.4.x  | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability or a critical issue (such as a command injection flaw in the CLI tools), please **do not open a public issue**. 

Instead, please report it via GitHub's private vulnerability reporting feature in the "Security" tab of this repository, or contact the maintainers directly. We will ensure the issue is addressed and a patch is released as quickly as possible.
