# Getting Support

If you run into any issues, have a question, or want to suggest a new feature for the ISO Compressor, I'm here to help!

## 1. Join the Discord
The fastest way to get help, ask questions, or just chat about retro gaming is to join the official Discord server.
👉 **[Join the Discord Server](https://discord.gg/BxdrA6gfZg)**

## 2. Open a GitHub Issue
If you found a verifiable bug or want to officially track a feature request, please open a public issue on GitHub.
👉 **[Open a GitHub Issue](https://github.com/wako69420/iso-compressor/issues)**

---

## 🔒 Critical Security Bugs
If you happen to discover a critical security vulnerability, please **do not** open a public issue. Please contact me privately so I can patch it safely before it becomes public.
