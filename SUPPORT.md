# 🛠️ Support & Troubleshooting

Thanks for using ISO Compressor! Before you open a new issue, please check the options below to get the fastest help possible.

## 👾 1. Join the Discord (Fastest!)
If you are having trouble getting the app to work, need help with emulators, or just want to ask a quick question, **please join the Discord server first!** 
I am highly active there and can usually help you troubleshoot your problem in real-time.
👉 **[Join the ISO Compressor Discord](https://discord.gg/BxdrA6gfZg)**

## 🐛 2. Opening a Bug Report or Feature Request
If you are certain you have found a bug in the code, or you want to officially request a new feature, feel free to open a GitHub Issue below. 
*(Note: Please include as much detail as possible, such as your Operating System, the specific game you are compressing, and any exact error messages).*

---

## 🔒 3. Critical Security Bugs
If you have discovered a critical security vulnerability, please **do not** open a public issue. Contact me privately via Discord so I can safely patch the exploit before it becomes public.
